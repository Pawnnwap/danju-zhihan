# 04 · 试点周历与工时台账（退出触发④的计量件）

本文件解决两件事（评审 B-R8①③⑤）：材料把"90 天试点"和几个季节性指标写在一起却没有逐周日历；退出触发④拿"项目人自己的工时"当标尺，却没说工时记在哪、谁复核。**没有这两样，指标与触发条款都只是措辞。**

## 3. 台账规则与它的限度

- **签约当日先固定 n 与判据**（评审 B-R9①）：把户数 n、由 n 换算出的周活跃分母（n × 13）与达标／判失败两个绝对数写进本表下方"判据换算"首行，此后只读不改；n=1 时全部指标只报分子分母与案例，不宣布达标或未达。
- **"计划工时"列现在的状态与限度（评审 A-R11⑧ 自查）**：本表"计划工时"格**尚未逐行填数**，只有 `docs/03` §2 的 ①–⑩ 分项与 86–94 小时总数；材料闸门也**只核"85–95 小时"这个字面串**，并不核对逐行相加。也就是说：这张表目前是"可填的账本"，不是"已经算过的账"。启动当周（W-4）必须把 ①–⑩ 摊到各行并填实数，此后对外引用 85–95 小时时才可以说"分项可加到本表"；在那之前，本表不得被引用为工时证据。
- **每周日填一次**，三列一起填：日期、计划/实际工时、本周产出对应的凭证编号。工时以 0.5 h 为最小格。
- **台账随仓库公开，凭证原件不公开**（群名/昵称/头像打码后才编号，见 docs/03 §伦理）。
- **复核只有半条外部路径**：复盘时把台账与凭证一起放进对外证据包，第三方能核对"台账声称的执行日"与"看板截图上的页面日期字段"是否同日；**没有第二个人替我记工时，这就是自我裁判**，材料不把它包装成第三方审计。
- 退出触发④读的是这张表的行数与日期（连续 6 周低于 2 小时/周即触发），不凭印象。
- 若某周确实没做，工时装 0 也要写一行——缺行会让"连续 6 周"无法判定。
